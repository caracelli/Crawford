LTDEV-2 - CRIPTOGRAFAR O CLIENT SECRET DO GRAPH (DPAPI) PARA O APPSETTINGS
==========================================================================

O Client Secret (token do Graph) entra CRIPTOGRAFADO no appsettings.json, nunca em
texto puro. O EmailIndexingService descriptografa sozinho ao iniciar: todo valor de
configuracao que comeca com "AQAAANCM" e aberto pelo DpapiConfigurationSource do
Crawford-Framework (DPAPI do Windows, escopo LocalMachine).


REGRA IMPORTANTE
----------------
Criptografar NA PROPRIA MAQUINA QUE VAI RODAR O SERVICO.
O valor criptografado so abre no computador onde foi gerado:
  - o valor gerado numa maquina nao funciona em outra;
  - dev, HML e PRD: cada um gera o seu.
Se usar o valor de outra maquina, o servico para ao iniciar com o erro:
  Critical failure while describing key 'Graph:ClientSecret' via DPAPI.


PASSO A PASSO
-------------
1. Na maquina que vai rodar o servico, abrir o PowerShell.

2. Copiar e colar os comandos abaixo:

Add-Type -AssemblyName System.Security
$texto = Read-Host "Client Secret"
$bytes = [Text.Encoding]::UTF8.GetBytes($texto)
$cifrado = [Security.Cryptography.ProtectedData]::Protect($bytes, $null, 'LocalMachine')
[Convert]::ToBase64String($cifrado)

3. Quando pedir "Client Secret", colar o secret do aplicativo (o token do Graph)
   e apertar Enter.

4. O resultado e um texto longo que comeca com AQAAANCM... Copiar esse texto inteiro.

5. Colar no appsettings.json do servico
   (C:\Projetos\Service-ClaimEmailAutomation\EmailIndexingService\appsettings.json):

   "Graph": {
     "TenantId": "<tenant do Azure AD>",
     "ClientId": "<client id do aplicativo>",
     "CertificateThumbprint": "",
     "ClientSecret": "AQAAANCM...",
     "ProcessedFolder": "Processados",
     "RejectedFolder": "Rejeitados",
     "FoldersAtRoot": false,
     "DeltaStatePath": "delta-state.txt"
   }

6. Rodar o servico (F5 no Visual Studio). Se iniciar sem o erro de DPAPI e a
   varredura ler a caixa, esta certo.


OUTROS SEGREDOS
---------------
O mesmo processo vale para os outros valores sensiveis do appsettings
(ex.: RabbitMQ.Password, senhas de banco): rodar os mesmos comandos com o valor
e colar o resultado AQAAANCM... no campo correspondente.


PARA CONFERIR (opcional)
------------------------
Para descriptografar e conferir um valor, na MESMA maquina:

Add-Type -AssemblyName System.Security
$cifrado = Read-Host "Valor AQAAANCM..."
$bytes = [Security.Cryptography.ProtectedData]::Unprotect([Convert]::FromBase64String($cifrado), $null, 'LocalMachine')
[Text.Encoding]::UTF8.GetString($bytes)

Se der erro, o valor foi gerado em outra maquina: gerar de novo nesta.
