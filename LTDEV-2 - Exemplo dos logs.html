Dados reais dos testes de 23/10/2026 (máquina local). No staging muda só o ServiceName (Staging EmailIndexingService) e o MachineName (nome do servidor).

O NLog.config grava o mesmo evento em três lugares:
  • Arquivo: <pasta do .exe>\log\emailindexing-AAAA-MM-DD.log (um por dia)
  • Banco: LogDB.dbo.Logs, via ConnectionStrings.LogConnection
  • Console: a janela do serviço, quando roda na mão
Nível mínimo: Info (Info, Warn, Error).

O que é cada coluna

ColunaConteúdo
CreateDateHora em que o banco gravou a linha (SYSDATETIMEOFFSET())
MachineNameServidor onde o serviço roda
ServiceNameFixo no NLog.config: EmailIndexingService (no staging, Staging EmailIndexingService)
LoggedHora do evento, em UTC (no Brasil, subtrair 3 horas)
LevelInfo, Warn ou Error
LoggerClasse do serviço que gerou o evento
MessageA mensagem
PropertiesValores da mensagem separados por | (bom para filtrar: Failed=1, InternetMessageId=...)
CallSiteMétodo onde aconteceu
ExceptionErro completo, com a pilha (vazio quando não há erro)

3. O que aparece em cada situação

SituaçãoNívelMensagem
Fim de cada varredura (a cada IntervalMinutes)InfoScan: read=N indexed=N rejected=N failed=N purged=N
E-mail que falhou ao indexar (vai para Rejeitados e é encaminhado com o motivo)ErrorEmail not indexed: <id do e-mail> + exceção
Banco fora na leitura da configuração (usa a última lida)WarnCould not read the configuration from BRS Cloud; using the last one.
Varredura inteira falhou (banco, Graph ou pasta): dispara o aviso por e-mailErrorScan failed. + exceção
País sem caixa configurada no ParameterRootWarnNo mailbox configured for the service user's country; scan skipped.
Não conseguiu mover / encaminhar / avisar o reguladorWarnCould not move ... / Could not forward ... / Main adjuster not notified ...
Aviso de erro crítico sem destinatário (EmailIndexingAlertBox vazio)WarnCritical error alert not sent (no AlertBox/Mailbox configured)

E-mail indexado ou recusado com sucesso não gera linha própria: entra só na contagem do Scan. Para ver cada um: pastas Processados/Rejeitados da caixa e os anexos do sinistro.

4. Consultas úteis no LogDB

-- últimas ocorrências do serviço
select top 50 Logged, Level, Message, Exception
from dbo.Logs where ServiceName = 'Staging EmailIndexingService'
order by Id desc

-- só erros e alertas do dia
select Logged, Level, Message, Exception
from dbo.Logs
where ServiceName = 'Staging EmailIndexingService' and Level in ('Warn','Error')
  and Logged >= cast(sysutcdatetime() as date)
order by Id desc

-- varreduras com falha
select Logged, Message from dbo.Logs
where ServiceName = 'Staging EmailIndexingService' and Properties like '%Failed=[1-9]%'
order by Id desc
